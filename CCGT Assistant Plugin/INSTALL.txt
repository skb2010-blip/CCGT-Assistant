CCGT Assistant 0.3.6 — Installation

1. Copy this CCGT-Assistant folder into your vault's .obsidian/plugins/ directory.
2. Confirm manifest.json, main.js, and styles.css are directly inside .obsidian/plugins/CCGT-Assistant/.
3. Open Obsidian Settings → Community plugins and enable CCGT Assistant.
4. When updating, back up the existing plugin folder, disable the plugin, replace the files, then re-enable or reload Obsidian.

See README.md for the feature guide, default folder structure, workflows, troubleshooting, and limitations.
